1. What did you improve?

I gave the original website a more modern, user-friendly sushi restaurant feel.

- Replaced the basic design with a warm, premium Japanese-inspired theme.
- Added editorial typography using Lora + Nunito.
- Localized the website for Mylapore, Chennai, with INR pricing and FSSAI Veg/Non-Veg indicators.
- Expanded the menu with categories like Nigiri, Maki, Sashimi, Hand Rolls, and Platters.
- Improved the responsive design for mobile, tablet, and desktop.
- Reworked the layout into a modular React component structure.

2. What new feature did you add?

I added several interactive features that were missing from the original website:

- Real-time menu search and category filtering
- A favorites system for dishes
- A dish details popup with ingredients, allergens, piece count, and dietary information
- A shopping cart drawer with quantity controls and subtotal calculation
- Promotional offers with coupon codes
- Customer reviews and ratings
- FAQ accordion
- Location section with opening hours and Google Maps directions
- Newsletter subscription
- Micro-interactions and hover animations throughout the interface

3. Why did you choose that feature?

I focused on features that would actually help restaurant customers instead of adding things just for decoration.

Customers often want to quickly find a specific dish, check if it’s vegetarian, see what ingredients it contains, and decide what to order. That’s why I prioritized search, filters, dietary indicators, detailed dish information, favorites, and cart functionality.

The goal was to make the website feel like a real restaurant ordering experience, not just a static showcase page.

4. What technologies did you use?

- React 19 for building a modular and interactive frontend
- Vite for fast development and builds
- Tailwind CSS v4 for responsive styling
- Vanilla CSS for custom design tokens, animations, and UI effects
- Lucide React for icons
- Google Fonts using Lora and Nunito for the typography
- React hooks like "useState" and "useMemo" for managing interactions and filtering

5. What did you personally refine?

I personally guided the overall design and user experience of the project.

I refined:

- The overall visual hierarchy and page structure
- The color palette and Japanese-inspired visual identity
- Typography and spacing
- Menu card layouts and interactions
- Search and category-filter behavior
- FSSAI Veg/Non-Veg indicators for Indian users
- The dish detail modal and cart experience
- Responsive behavior across different screen sizes
- Hover states, animations, and micro-interactions
- Chennai/Mylapore-specific content and localization

My main focus was making sure the website wasn’t just visually attractive, but also practical, intuitive, and believable as a real restaurant website.
